## 定位

joinwell52 研究中心是一个由真实工程实践驱动的独立研究门户，聚焦：

- AI 工作数据与治理；
- 多 Agent 正式协作；
- 数字员工架构；
- AI 软件工程与 Runtime；
- 面向中小企业的可落地 AI 工作系统。
