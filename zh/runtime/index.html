Q-20260913-01 · 长周期 Agent 恢复必须在同一 Checkpoint 边界对齐推理上下文与环境状态

经 Skill 02 筛选后选自 SIG-20260913-005。AgentRewind 暴露的是一个不依赖论文名称也成立的长周期恢复问题：错误可能同时污染 Model-visible Context 与 Agent 正在操作的 Environment，因此只回滚其中一侧，会让 Worker 在认知状态与现实状态不一致的情况下继续工作。该一手研究使用对齐的 Context / Environment Checkpoint，并在不同 Task、Model、Execution Strategy 与 Harness 上进行评估，证据强度高于今天几个只有单一实现的工程 Signal。数字员工的有界问题是：一次 Recovery Checkpoint 必须绑定哪些 State Identity，失败尝试中的哪些信息可以安全保留，以及恢复后的 Worker 在再次行动前需要什么证据。它与 9 月 4 日 Interrupted-tool Replay-safety 对象不同，后者研究中断调用是否会被自主重放；也不同于 9 月 11 日 Memory-evidence 对象，后者研究语义 Memory Role 变化时如何保留 Atomic Observation；今天研究的是错误已经在长周期任务中传播后，如何协调回滚认知状态与环境/效果状态。

Q-20260913-02 · Agentic Audit 不能因为搜索结束就算完成，Coverage 需要独立证据

经 Skill 02 筛选后选自 SIG-20260913-004，作为强一手 Failure Result。它形成的有界架构问题是 AI-assisted Audit 的 Completion Truth：Agentic Search 可以完成自身搜索程序，却仍然没有满足“相关证据已经被覆盖”的业务命题。Anthropic 报告称，最初约 14.1 万份 Transcript 的扫描漏掉了相关案例；后续复查发现第 4 起事故后，调查范围扩大到约 4.81 亿份 Transcript，并覆盖更多 Log Family。因此，行业架构的问题是：在把 Audit 称为完成之前，必须具备什么可观察的 Evidence Inventory、Coverage Metric、Blind-spot 声明与独立 Follow-up Process。该对象复用了 9 月 10 日已经选过的一手来源，但没有重复当时的研究问题：9 月 10 日研究的是当 Agent 与 Monitor 可能共享错误前提时，高影响执行授权为何需要外部 Scope Fact 与独立 Live Enforcement；今天单独研究 Audit Coverage，以及为什么不能从 Search Process Completed 推导 Evidence-complete Audit。复用来源使 Novelty 低于全新的证据基础，但 Failure Proposition 与 Completion Contract 是实质不同的。
