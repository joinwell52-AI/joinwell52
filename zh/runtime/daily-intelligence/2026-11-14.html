研究分析 ​

A1 · 动作授权需要绑定环境、凭证与代码来源 ​

O2、O3、O6、O11、O13、O16、O20、O27、O28

证据支持：多个实现分别补充环境 selector、机器凭证归属、最小化 secret 暴露与 hook/import/path 边界。待验证：CodeFlowMu 在执行时是否同时绑定岗位主体、组织、连接环境和可信代码。实验候选：同名服务跨环境调用、项目同名模块劫持、symlink 写入；适配层/Runtime 议题，不能直接推成 FCoP 内核要求。

A2 · 恢复要结算真实结果，暂停也要耐久化 ​

O1、O5、O7、O9、O12、O17、O19、O26、O29

证据支持：提交、回执、暂停与重试各有不同失败窗口；Paperclip 的 queued brake 与 unknown receipt 修复给出具体反例。待验证：将 FCoP 工件收据与 Runtime 操作结算映射能否减少重复副作用和永久 fence。实验候选：提交后断线、模型等待中暂停再断电、乱序确认；须保留未知结果，不能自动等同失败。

A3 · 协议比较要沿真实连接链拆层 ​

O2、O4、O6、O10、O11、O21、O25

证据支持：MCP 协商/工具技能、OAuth 机器身份、PRP controller/Runner turn 各解决不同层面问题。另 MCP #3541 已合入六个月规范周期与 2027-03-30 目标公告，目标不等于新协议已发布。体验候选：PRP 契约及 MCP Skills，在固定版本、License/依赖核对后体验；FCoP 文件/工件协调可互补，当前没有替换内核的依据。

A4 · 验收本身也需要治理与独立证据 ​

O14、O15、O23、O24

证据支持：Beads 补派生事件 actor，browser-use 使用同模型事后 judge，赵越框架记录实际模型并排除协调者参与审查。Anthropic 新文要求校准 grader、预先定义指标、报告不确定性；同模型 judge 不能叫独立验收。实验候选：用隐藏结果检查同模型、异模型与规则验收的一致性，成本与漏判率均记录。

A5 · 竞品成熟度需由故障反例和交付边界重估 ​

O5、O7、O8、O12、O13、O20、O22

Paperclip 学习与竞争风险均高，但千并发仍属目标；Eigent 的 Git Space 并发修复是团队交付直接证据；Orkas 的 macOS 负对照比测试数量更有价值，但平台覆盖有限；Agentlas 的更新通道与 hook 信任须一起看。体验候选按这四条故障路径选择，尚未安装。未核实新的商业/License 结构性变化，本轮不据此调整商业判断。
