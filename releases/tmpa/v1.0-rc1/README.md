# TMPA V1.0 publication dossier - RC1

This immutable-candidate directory packages the currently reviewed TMPA publication baseline without prematurely promoting the documents to V1.0:

- Architecture Paper A0.9;
- Core Specification S0.6;
- Implementation Case I0.8.

The English and Chinese editions share one work identity per document while retaining language-specific titles and citations. `SHA256SUMS` authenticates every packaged source, metadata and PDF artifact. `MANIFEST.json` records the build inputs and claim boundary.

RC1 is a review artifact, not the final V1.0 tag or a DOI-bearing archival release. Final author identity details, ORCID, license confirmation, Zenodo deposit and V1.0 promotion remain explicit release decisions.
