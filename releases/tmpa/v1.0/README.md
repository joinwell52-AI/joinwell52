# TMPA V1.0 publication dossier

This directory is the final, checksummed publication dossier for:

- TMPA Architecture Paper A1.0;
- TMPA Core Specification S1.0;
- TMPA Implementation Case I1.0.

English and Chinese editions retain separate publication files and citation metadata. `SHA256SUMS` authenticates every packaged source, metadata, and PDF artifact; `MANIFEST.json` provides the machine-readable inventory; `BUILD.json` records source inputs and the claim boundary.

The Implementation Case reports an author-run CodeFlowMu V1.8.0 execution against the exact TMPA Core S1.0 bundle: C01–C14 14/14 PASS across 71 mandatory assertions. It is not independent certification, universal conformance, theory proof, hallucination elimination, or independent adoption.
