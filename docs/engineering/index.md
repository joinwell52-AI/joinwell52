# Engineering Watch / 工程观察

Engineering Watch tracks open-source systems whose runtime, workflow, recovery, skill, observability, or multi-agent design may affect CodeFlowMu.

工程观察持续跟踪可能影响 CodeFlowMu 的开源系统，重点关注 Runtime、Workflow、恢复、Skill、可观测与多 Agent 工程。

- [OpenHands / Agent Canvas](./openhands)

The goal is not feature imitation. Each report identifies what to learn, what to ignore, and what changes the CodeFlowMu engineering roadmap.

目标不是追齐功能，而是明确哪些值得学习、哪些应忽略、哪些会实质影响 CodeFlowMu 工程路线。
