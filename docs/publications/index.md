## Publication path / 发布路径

```text
Internal draft → Public draft → Stable release → Preprint / DOI → Venue submission
内部草稿 → 公开草稿 → 稳定版本 → 预印本 / DOI → 会议或期刊投稿
```

Public drafts are works in progress and should be cited with their explicit version and access date.

公开草稿仍在持续修订，引用时应标明明确版本和访问日期。
