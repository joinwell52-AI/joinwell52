# After the Causal Label: What an Attribution Module Probe Establishes

Can two failed criterion sets plus a nonempty string be enough to produce a harness-caused label? In synthetic calls to the pinned module examined here, yes. More revealingly, a link whose two endpoints were absent from the failed sets still activated that label while its traced-failure count was zero. This combination makes the distance between a label's name and its evidentiary state concrete.

This article reports only the module's local contract: programmatic activation of a candidate mechanism chain and completed causal validation are different evidence states. It does not reproduce the complete benchmark, estimate real-run misattribution rates or establish that callers lack prevalidation.

## Two failures do not yet make a causal chain

TraceTrial separates task-side performance, harness-side criteria and the availability of the measurement apparatus. The distinction matters: a wrong task result does not automatically establish a harness defect, and a zero harness criterion does not by itself show that the harness caused task failure. The paper sets an additional threshold for propagation claims: confirmed endpoints, observable intermediate distortion, supported event order and review of competing explanations. [TraceTrial v1, §3.5, Table 5 and Appendix D.3](https://arxiv.org/pdf/2610.32285v1)

Evidence authority also depends on the question. Environment state supports actual effects; native model-facing records support what information was delivered; provider records support only captured structured declarations. Contiguous normalized sequence numbers are a presentation order, not a newly established causal order. On that basis, a candidate link and an evidence-corroborated link remain different states. [TraceTrial, §3](https://arxiv.org/pdf/2610.32285v1)

## A narrow experiment at an exact code revision

The completed same-date Analysis executed 12 calls to the original standalone attribution module at reading-time revision `98a381307184fa4212db3466b21b4c92a031940b`, using synthetic criterion verdicts. The recorded environment was Python 3.12.9 on Windows. Production reuses the completed measurements and runs no new experiment.

This was not native-trace replay: no benchmark task, real archive, private oracle, semantic judge or caller was executed or inspected by the probe. The [internal probe record](/assets/evidence/2026-11-13-sig-20261113-007/article-evidence.json) retains complete inputs, outputs, source digest and environment. The table lists all 12 calls. Its attribution names are literal module outputs, not this article's causal conclusions about real runs.

| Synthetic condition | Module attribution | Traced failures |
|---|---|---:|
| Both layers fail; no link | agent_caused | 0 |
| Both fail; empty chain | agent_caused | 0 |
| Both fail; whitespace-only chain | agent_caused | 0 |
| Both fail; one-character placeholder chain | harness_caused | 1 |
| Both fail; harness link endpoint nonexistent | harness_caused | 1 |
| Both fail; both link endpoints nonexistent | harness_caused | 0 |
| Both layers pass | clean | 0 |
| Only harness layer fails | harness_defect_absorbed | 0 |
| Only agent layer fails | agent_caused | 0 |
| Failed apparatus with a nonempty chain | inconclusive_device | 0 |
| Harness layer has no measurable criterion | inconclusive_unmeasured | 0 |
| Agent bypasses the designated observation channel | agent_caused | 0 |

All declared assertions passed. Empty strings, whitespace, apparatus failure and unmeasured layers are important negative controls: the module does not attach a harness-causal label to every input. The final case also applies the code's operational treatment of bypass-affected observation criteria, rather than treating them as intrinsic harness defects.

The central placeholder input can be abbreviated as follows. This is an excerpt from the executed input, not an additional experiment:

```text
failed harness criteria: H1
failed agent criteria: A1
candidate link: H1 -> A1
chain: "x"
output attribution: harness_caused
```

Replacing both link endpoints with identifiers outside the failed sets preserves the causal label but reduces the traced count to zero. The count checks whether the agent endpoint belongs to the failed set; the joint-failure causal branch requires only that an accepted link remains. Those predicates differ. [Pinned attribution module](https://raw.githubusercontent.com/TraceLite-AI/TraceTrial-Bench/98a381307184fa4212db3466b21b4c92a031940b/tracetrial_bench/attribution.py)

## Activation and corroboration are separate contracts

In this module, `is_substantiated` tests whether chain text remains nonempty after trimming whitespace. Its name may suggest empirical substantiation, but the property does not perform the paper's endpoint, distortion, order and competing-explanation review. The internal probe exposes the acceptance range of that program predicate.

The module's `harness_caused` output should therefore be read as activation of a candidate mechanism chain, without automatically promoting it to completed causal validation. The paper's operational interpretation preserves this distinction too. The code's names and executable conditions need to be read together. [Paper propagation rules](https://arxiv.org/pdf/2610.32285v1); [original module implementation](https://raw.githubusercontent.com/TraceLite-AI/TraceTrial-Bench/98a381307184fa4212db3466b21b4c92a031940b/tracetrial_bench/attribution.py)

This also constrains the benchmark numbers. The paper reports 95 tasks, nine model groups and four harnesses, giving 3,420 selected cells with one retained execution per cell, including replacements. Of 1,700 joint-shortfall runs, 842 activate at least one candidate link: a conditional 49.5%. These are source-reported archive counts, not locally reproduced results. The percentage is neither causal accuracy nor a validated propagation rate. A zero caused by an empty required evidence selector does not independently establish a defect in the subject under test. [TraceTrial, §§4–5](https://arxiv.org/pdf/2610.32285v1)

## A prevalidated caller could change the interpretation

The strongest alternative is that the module deliberately consumes already validated links. If a caller has checked endpoints and mechanism chains, repeating those checks here may be unnecessary. This probe did not audit callers or the links supplied by real archives. Malformed synthetic inputs do not establish an exercised production failure.

Version binding is another limit. The reading-time commit is not established as the paper's experimental freeze. The paper and current repository use different manifest names; the current manifest's embedded document digest differs from the captured v1 paper digest and names another PDF file. Byte identity is therefore unestablished. The mismatch alone does not show changed task membership. Neither final score archives nor benchmark executions were recomputed here. [Pinned task manifest](https://raw.githubusercontent.com/TraceLite-AI/TraceTrial-Bench/98a381307184fa4212db3466b21b4c92a031940b/Task/final.manifest)

These limits are not an allegation of fraud. The paper's stronger manual-review threshold and a narrow local module contract can coexist.

## Preserve the evidence state, not only the label

A design interpretation supported by these observations is to retain separate states for criterion failures, candidate links, endpoint checks, intermediate distortion and event-order review, with responsibility assigned to the layer performing each check. A single strong causal name makes it easy for downstream readers to mistake a pending explanation for a completed judgment. Missing evidence should remain visible as missing.

Actual effects and interaction requirements deserve the same separation. In a paired paper case, correct final values coexist with repeated actions that were required to occur exactly once. Output correctness and interaction compliance therefore need different evidence. MAST's categories of incomplete verification, incorrect verification and premature termination supply useful comparison vocabulary, but do not independently reproduce this module or establish the same propagation chain. [TraceTrial paired cases, Appendix F](https://arxiv.org/pdf/2610.32285v1); [MAST v3](https://arxiv.org/html/2503.13657v3)

## What remains to be established in real runs

This probe answers what inputs the module accepts. It cannot answer how many real candidate chains survive endpoint, distortion, event-order and competing-explanation review. That requires binding selected runs, task revisions, native traces, judge prompts and final scorecards to one experimental version, then examining how links enter the module.

Until that evidence exists, preserve two states: the program has activated an explanation; whether causal evidence suffices remains unresolved.
