# Before Reading a Collusion Score, Ask Who Survived the Label Rule

A case casts the target vote but has no readable private-stance record. In our synthetic-input check of pinned source, it receives no strict “joining” label: it is excluded. With the same missing stance and no target vote, the function returns a negative label. Before any score is interpreted, evidence availability and combination rules have already selected the comparison population.

This is not evidence that a monitor fails. The narrower judgment is that interpreting multi-agent collusion monitoring requires knowing what evidence labels need, which cases are excluded and how missing evidence is handled. Otherwise, even a valid ranking score may answer a narrower question than the reader assumes.

## Strict labels define the population first

The inspected research considers instruction cues, decision cues and monitoring scores. Its strict choice-label function does more than ask whether an agent cast a target vote. It also reads private-message stance signals and combines the two judgments. In the pinned source, strict mode retains both-positive cases as true and both-nonpositive cases as false; disagreements become null and leave that strict comparison.[1][2]

Null is not another negative label: it means exclusion. Replacing “vote or private agreement” with “both” changes both the positive criterion and the retained set. Strict mode can improve label agreement, but a score based on it concerns this selected population. That is an interpretation of the measurement mechanism, not a statistical finding from recomputed author data.

The inspected implementation uses scenario-group cross-fitting and rounds 1–4. Source code establishes these intended operations, not correctness of every real episode annotation or recomputation of episode contents and outputs.[2]

## What six synthetic cases establish

The same-day research analysis extracted and executed the strict choice-label and option-relabeling functions at commit `d4adba6120246098b7f54dddd6af0782b4a47662`. Inputs were synthetic configuration and stance files, not the paper's dataset. NumPy was unavailable. Only for the simple scalar lists in these fixtures, Python's standard-library mean replaced its mean call; array operations, training and model inference were not emulated.[3]

| Synthetic condition | Any-positive label | Strict agreement label |
|---|---|---|
| Positive target vote and positive private stance | True | True |
| Target vote only | True | Null, excluded |
| Private stance only | True | Null, excluded |
| Both nonpositive | False | False |
| Missing private stance, positive target vote | True | Null, excluded |
| Missing private stance, nonpositive target vote | False | False |

The table reports an internal isolated-function experiment, not independent reproduction. Strict labeling retains one true and two false cases and excludes three of these six fixtures. These counts describe deliberately constructed cases; they are not estimates of real-data coverage or missingness.[3]

The tested function treats missing private stance as nonpositive. Consequently, the last case receives the same label as a case with two observed nonpositive signals, despite a different evidence state. It should not be described without qualification as an observed refusal. Removing the entire stance file also turns the formerly both-positive case into an exclusion, while the formerly private-only case becomes false. This exposes the function's evidence dependency, not the prevalence of missingness in released data.[3]

The same isolated experiment checked four option-label combinations and nonmatching text controls. The pinned generator rewrites canonical option references to current fair and target labels, and the four fixture outputs behaved as specified. This establishes the tested substitutions, not semantic correctness of every real episode's options and stance labels.[3][4]

## Ranking, alarms and observation time are different quantities

On the committee hard-negative comparison, authors report agent AUROC falling from 1.00 to 0.61 when briefing and private context are removed, while a same-prompt decision probe retains 0.73. AUROC measures ranking discrimination. This intervention also changes the input distribution, so it does not cleanly identify whether a score reflects a goal or contextual cues.[1]

High ranking performance does not ensure a deployed threshold's false-alarm rate. Authors report committee-to-code-review and reverse-transfer AUROC of 0.994 and 0.966, while thresholds set for 1% source false alarms yield 2.5% and 4.0% on target data. An unretrained probe scores 0.50 on the emergent-collusion episodes used. These remain the authors' experimental results, not measurements from our function checks.[1]

The inspected stored author results give a more direct example. In the no-brief experiment, the instruction probe has AUROC 0.99468 against the honest adapter while run-level false alarms on controls are 0.21212 and 0.28283. The decision probe flags 14% of implanted runs with no observed control alarms. Agent-level ranking and run-level alarms use different units and cannot substitute for one another. Zero observed alarms cannot be expanded into zero false-alarm risk.[5]

Observation time also changes the question. The authors' post-vote rule reaches AUROC 0.990 on successful attempts, but before voting it has no outcome to read. The main evaluation instead scores all attempts before the vote. Retrospective screening and prospective detection have different information and population conditions. Our label-mechanism probe neither recomputes these numbers nor supplies an empirical correction or refutation.[1]

Our engineering interpretation is to report target behavior, required label evidence, retained and excluded counts, scoring time, observation unit and actual threshold errors together. Those facts determine which decisions a reader can reasonably base on the score.

## Label purity has a defensible scope

Strict labels are not inherently wrong. Researchers can deliberately exclude mixed signals to compare participants and nonparticipants with consistent evidence. If actual episode stance files are complete, the missing-evidence branch may have no effect on the original results. This synthetic experiment does not establish a defect in the intended complete-data use.

The corresponding cost is that coverage needs to be visible: excluded mixed behavior may still occur at deployment. We did not measure its real-world prevalence, trained evasion or spontaneous secret collusion. Labels depend on the generator and stance model; humans did not review every audit-flagged run. These limits continue to constrain interpretation.[1][2]

Archive metadata identifies version 1.2 as corrected, including concealed-message analyses missed in 1.1. Preregistration Amendment 7 records option-label issues affecting 572/1000 main attempts, with adapters not retrained. These are version and author-amendment records. Corrected raw episodes and activations were not obtained here; bootstrap analyses and complete outputs were not recomputed, and implanted adapter weights are withheld. Archive identity and a DOI cannot fill these empirical gaps.[1][4][6]

## The missing next evidence is episode evidence

The discriminating next evidence would independently examine corrected raw episodes and their labels and exclusions: does missingness actually occur, how common are mixed cases, and do independent annotators agree with private-stance judgments? Only then can further work test whether thresholds retain expected false alarms on realistic changing honest traffic, and whether no-brief separation reflects goals or training-style residue.

This study answers how selected functions choose the comparison population. It does not establish the prevalence of those populations in actual data or whether general collusion can be detected. Reporting who survives the label rule gives a score a defined object of interpretation.
