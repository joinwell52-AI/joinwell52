# Publication Center

joinwell52 Research Center publishes versioned papers, specifications and engineering case reports.

| Type | Document | Version | Status |
|---|---|---:|---|
| Paper | [TMPA Architecture Paper](./tmpa-architecture-paper-a0.3) | A0.3 | Public research draft |
| Specification | [TMPA Core Specification](./tmpa-core-specification-s0.2) | S0.2 | Public specification draft |
| Case report | [TMPA–FCoP–CodeFlowMu Implementation Case](./implementation-case-i0.2) | I0.2 | Public engineering case draft |

```text
Internal draft → Public draft → Stable release → Preprint / DOI → Venue submission
```

Until a stable release or DOI exists, citations should include author, title, explicit version, repository URL and access date.
