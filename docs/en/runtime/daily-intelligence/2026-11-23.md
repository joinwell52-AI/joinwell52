## Research analysis

### A1 · Separate input, result and display governance

O1 / O2 / O3 / O4 / O5 / O24

Evidence: SDK proposals place transforms before traces/streams/storage; Orca redacts status at producers, showing UI masking is insufficient. Unverified: missing callbacks, restored object changes, children, media/log bypasses and fail-closed behavior; input changes can alter the authorized action. Carries 2026-11-19 A1/A2 and 2026-11-22 A3. Candidate: synthetic-secret negative controls across tool/stream/trace/persistence with pinned branches; unrun, no local defect claim.

### A2 · Distinguish receipt, consumption, acceptance and completion

O5 / O6 / O12 / O18 / O19 / O23 / O31 / O33

Evidence: sharing a turn is not task completion; queueing is not delivery; recovering a digest is not retry-effect protection. November 22 local results establish per-file requeue reconstruction, not PM use, accepted artifact version or independent QA. Carries 2026-11-19 A3 and 2026-11-22 A2; next candidates are same-path version two, judge failures and lost replies. Compare task/artifact/receipt relations in FCoP, while Runtime performs I/O/retries.

### A3 · Separate location, identity and authority across hosts

O7 / O9 / O10 / O20 / O21 / O25 / O30 / O32

Evidence: connection reuse needs identity continuity, handoffs recheck authority, paired asks need local approval and replies return to origin. Broader work visibility may reduce duplicate work but requires cross-user tests. Request/reply/provenance contracts are FCoP comparison points; pairing, credentials and admission belong to Runtime/adapters. Paperclip remains main radar; Orca second-circle attention rises; preserve Superset's original mapping to Paradev without editing Registry.

### A4 · Distinguish waiting, continuation and infrastructure failure

O8 / O11 / O12 / O13 / O14 / O15 / O16 / O22 / O26 / O27 / O28 / O29

Explicit continuation, expected-turn monitoring, restart recovery, full-disk budgets and FD concurrency affect durable work through different failure modes. Fewer conversational confirmations do not remove security gates; audit without a handler is not enforcement; merged wake code is not deployment. Carries 2026-11-19 A4/A5 and 2026-11-22 A1/A5; disconnect-history, shared-turn failure, dual-host recovery and resource-exhaustion tests remain candidates.
