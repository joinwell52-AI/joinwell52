# Industry Architecture

This section studies products that package, operate, manage, or govern AI labor.

## Current coverage

- **ServiceNow** — Autonomous Workforce, workflow execution, escalation, and AI Control Tower;
- **Workday** — Agent System of Record, ownership, cost, compliance, and lifecycle.

The goal is not vendor introduction. Each report analyzes positioning, runtime, governance, workflow, strengths, weaknesses, lessons for CodeFlowMu, and impact on TMPA.

Vendor claims are treated as vendor-reported evidence unless independently verified.
