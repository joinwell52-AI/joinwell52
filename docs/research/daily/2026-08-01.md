# 2026-08-01 — Public Research Center Architecture / 公开研究中心架构

## Decision / 决议

The existing `joinwell52-AI/joinwell52` repository is rebuilt as the public home of TMPA Research Center.

现有 `joinwell52-AI/joinwell52` 仓库全新重构为 TMPA Research Center 的公开研究主页。

## Public role / 对外职责

The site publishes:

- TMPA papers and specifications;
- daily and weekly research;
- Digital Employee governing architecture;
- industry and GitHub engineering analysis;
- future preprints, DOI records, and formal publication status.

网站公开发布：

- TMPA 论文与规范；
- 每日和每周研究；
- 数字员工纲领性架构；
- 行业与 GitHub 工程分析；
- 后续预印本、DOI 和正式发表状态。

## Editorial boundary / 编辑边界

The public repository contains curated research outputs. Internal CodeFlowMu implementation drafts, confidential business details, credentials, and unreviewed sensitive evidence remain outside the public site.

公开仓库只承载经过编辑的研究成果。CodeFlowMu 内部实施讨论稿、企业敏感信息、账号凭证与未经审核的敏感证据不进入公开网站。

## Technical architecture / 技术架构

```text
Markdown research documents
        ↓
VitePress
        ↓
GitHub Actions
        ↓
GitHub Pages
        ↓
https://joinwell52-ai.github.io/joinwell52/
```

Every push to `main` triggers a new static-site build and deployment.

每次向 `main` 推送内容，都会触发静态网站重新构建与发布。

## Public research loop / 公开研究闭环

```text
Daily Observation
→ Weekly Synthesis
→ Governing Architecture
→ Specification / Engineering Evidence
→ Paper
→ Preprint / DOI / Venue Submission
```

```text
每日观察
→ 每周综合
→ 纲领性架构
→ 规范 / 工程证据
→ 论文
→ 预印本 / DOI / 投稿
```
