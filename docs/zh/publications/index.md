# 出版中心

TMPA 研究中心以版本化方式公开论文、规范和工程案例。

| 类型 | 文档 | 版本 | 状态 |
|---|---|---:|---|
| 论文 | [TMPA Architecture Paper](./tmpa-architecture-paper-a0.3) | A0.3 | 公开研究草稿 |
| 规范 | [TMPA Core Specification](./tmpa-core-specification-s0.2) | S0.2 | 公开规范草稿 |
| 案例 | [TMPA–FCoP–CodeFlowMu Implementation Case](./implementation-case-i0.2) | I0.2 | 公开工程案例草稿 |

```text
内部草稿 → 公开草稿 → 稳定版本 → 预印本/DOI → 会议或期刊投稿
```

在获得稳定版本或 DOI 之前，引用时应注明作者、标题、明确版本、仓库地址和访问日期。
