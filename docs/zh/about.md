# 关于数字员工工场

数字员工工场由朱卫（joinwell52-AI）独立维护。工场持续生产数字员工工作成果；CodeFlowMu 与 FCoP 构成工程能力底座；TMPA 论文体系作为独立理论与规范层维护。

## 研究方向

- AI 工作数据与治理；
- 正式多 Agent 协作；
- 数字员工架构；
- 面向中小企业的 AI 部署；
- AI 软件工程、恢复、审计与评估。

## 研究方法

```text
真实工程
  ↓
可重建证据
  ↓
架构与规范
  ↓
论文与公开发布
```

数字员工是工场的产品层，CodeFlowMu 与 FCoP 是工程实现层，TMPA 是独立理论层。观察笔记记录数字员工在工作中看到的学术、开源与产业动态，不自动构成 TMPA 论文证据。
