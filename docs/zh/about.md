# 关于数字员工工场

数字员工工场由朱卫（joinwell52-AI）独立维护。工场持续生产可核验的数字员工工作成果，并公开研究方法、运行规范、工作记录、观察笔记和正式出版物。

## 当前数字研究员

当前能力版本是：

- **研究报告生产机 V1.3**；
- **Research Runtime Center V4**；
- **Research Runtime Scheduler V2.0**；
- **Research Skills V2.0**；
- **Research Intelligence System V1.0**。

研究报告生产机是一个通过 ChatGPT 实现的 Research Analyst 数字员工。它使用三条情报管线为三个长期栏目发现信号、筛选选题、推进研究、生产完整中英文报告，并通过 GitHub First 完成正式发版与验证。

## 产品与工程层级

```text
TMPA + FCoP
      ↓
CodeFlowMu + Digital Employee
```

- **TMPA：** 独立理论与规范层；
- **FCoP：** 基于文件的协同协议；
- **CodeFlowMu：** 数字员工开发与工作 Runtime；
- **Digital Employee：** 产品与交付层。

网站能力区按这个层级展示：TMPA 与 FCoP 在第一排，CodeFlowMu 位于第二排首位，随后是 Digital Employee。

**FCoP 4.0.5** 提供 MIT 开源 Python 库和可选的 Canonical MCP 适配器：**25 个工具、6 个资源，无资源模板**。Core 负责协议事实、验证和状态迁移；MCP 是 Core 的薄适配器。Runtime、Profile 预设、Host 配置和 Legacy 兼容均在 Base Protocol 之外。[软件归档](https://doi.org/10.5281/zenodo.23051275) · [FCoP 预印本 1.0](https://doi.org/10.5281/zenodo.22855630) · [FCoP 引用元数据](https://github.com/joinwell52-AI/FCoP/blob/main/CITATION.cff)。论文实验与补充材料使用冻结的 4.0.3 实现；4.0.5 软件更新不代表这些实验已重新运行。

## 三个研究栏目

- **数字员工：** 岗位、职责、工作流、运行、治理与评估；
- **行业架构：** OpenAI、Claude、Gemini、Cursor、GitHub Copilot、Microsoft Copilot Platform 等主要 AI 平台的产品和运行架构；
- **开源工程：** Agent Runtime、协议、SDK、工具、Benchmark、恢复与可观测性工程。

## 研究方法

```text
真实来源与工程
  ↓
可重建证据
  ↓
受治理研究生命周期
  ↓
完整报告生产
  ↓
GitHub 与网站发版
  ↓
架构、规范与公开出版
```

观察笔记记录数字员工在工作中看到的学术、平台与开源动态，不自动构成 TMPA 论文证据。
