# 恢复答案需要问题槽位，任务身份还不够

第一个问题已经回答“是”，第二个问题正在等待。如果两者只用任务身份寻址，重发第一个答案，就有把旧回复当成新问题答案的风险。LangGraph（可恢复智能体图执行框架）的已读变更包含这一过期答案场景的回归测试定义，同时又保留接受旧标识的兼容路径。把这两个事实放在一起看，比直接宣称“所有旧答案都会被拒绝”更有工程价值。[1]

这里其实有三个职责：识别当前答案槽位、兼容特定已存状态，以及从正确的位置重放已有答案。本次同日内部函数实验只执行了其中的窄片段，不能据此认定完整运行时正确、动作已经授权，或外部效果恰好发生一次。

## 任务身份太宽，答案槽位缩小了问题范围

固定提交中的新增标识函数，在没有已存答案时，直接使用任务命名空间作为哈希输入；后续问题则在哈希前附加分隔符与已有答案数量。已读回归将连续问题的标识预期从“相同”改成“不同”，同时保留第一个问题原有的命名空间身份。这里观察的是源码改动和测试定义，并未观察完整测试集通过。[1]

这种选择给答案提供了比任务更具体的地址，但并非简单地给源码中的调用位置编号。补丁中的并行调用回归按任务实际抛出问题的顺序处理；新增机制选择的边界，是已经存在多少个答案。因此，问题在重放中的位置仍然重要。

内部实验提取新增函数，把环境中不可用的哈希依赖替换成输入记录器。对一个示例命名空间，已有答案数量分别为零、一、二时，观察到以下输入。它们是**哈希前的原始输入，不是真实中断标识**。[3]

```text
ask:task-example
ask:task-example|1
ask:task-example|2
```

这支持“首槽输入不变、后续槽输入分离”的窄判断，不涉及真实哈希输出、存储行为或同时提交。上游过期答案回归预期：旧标识会因为不在待决集合而被拒绝，错误信息包含当前待决标识。但本研究没有执行这条完整约束路径。[1；3]

## 兼容是有范围的查找规则

已读恢复映射分支先查当前槽位标识；不存在时，还会查第一个标识作为旧状态回退。内部实验执行提取出的分支，从已经存有一个“是”的状态出发，观察到下列结果。[1；3]

| 交给隔离分支的映射 | 分支结束后的已存答案 |
|---|---|
| 当前槽位映射为“否” | “是”“否” |
| 只有旧首标识映射为“旧值” | “是”“旧值” |
| 当前标识为“当前值”，旧标识为“旧值” | “是”“当前值” |
| 只有未知标识映射为任意值 | 仍只有“是” |

当前映射优先，未知键在该分支中不追加答案。旧状态案例则具体反驳了“这次标识改动在所有状态下一律拒绝旧首标识”的说法。它不与完整约束路径中的过期答案回归矛盾：隔离查找与完整约束，是两个不同的证据对象。

我们的解释是：迁移审查需要核对哪些已存状态能进入回退分支、外围检查又如何限制它。函数级成功不能承担完整迁移安全的结论；反过来，仅因为新标识看起来更强就移除回退，也可能破坏原本有意支持的旧状态。本文没有建议执行这种改动。

## 地址正确，读取位置仍可能错误

官方中断文档说明，恢复会从节点开头重新执行，已有答案按索引匹配。这会产生另一种失败机会：答案列表正确，读取它的游标却已经向前走过。[2]

已读重试函数替换中断计数器，同时保留已有答案。在内部替身依赖实验里，已经前进过的计数器若不重置，下一次返回索引一；执行提取出的重置函数后，下一次索引为零，已存的“是”仍然保留。配置对象、暂存对象和计数器均使用替身，本研究没有在本地执行同步或异步运行时重试。[1；3]

这个区别很关键：槽位寻址决定新答案属于哪个待决问题，游标重置决定重放从哪里读取旧答案。一个正确，另一个仍可能出错。官方文档要求保持中断顺序的约束仍然成立；新标识没有让任意重排变安全。[2]

## 应用仍须承担哪些责任

对于需要审批的应用，答案寻址正确只是授权判断的一项输入。当前变更没有建立答案与不可变动作参数、批准者权限、有效期限、凭据范围或外部效果去重之间的保证。这是在本研究证据范围内未建立的能力，不等于断言所有外围应用都没有这些能力。

责任边界可以具体拆开：调用方提交回复和标识，已读查找逻辑形成被选中的已存答案，重放再按顺序消费已有回复。真正授权动作的应用，仍需拿出“批准的是哪个动作、依据什么权限执行”的证据。重试成功找回一个“是”，不能补回这些缺失的授权依据。

官方文档还提醒，节点可能已提交外部效果，却在完成前失败；重试便可能再次产生同一效果。因此，把操作放在提问之后，不足以建立恰好一次执行。本研究没有执行外部动作，也没有测量去重行为。[2]

接下来的验证对象应是完整路径：旧与新答案如何经过外围约束、受支持旧状态如何恢复、真实检查点后端如何处理并发提交，以及另行定义的应用授权生命周期。本次实验采用哈希输入记录器与替身对象，只是内部机制证据，既不是独立复现，也不是安全审计。回归定义和公开提交让设计意图可检查，并不代表普遍有效或已观察到完整测试集通过。
