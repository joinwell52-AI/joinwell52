## 研究分析

### A1 · 授权不止有token：行动者、人工确认与当前范围

依据：O2 / O4 / O5 / O7 / O18 / O39 / O40。

已有证据：个人OAuth、窄Retry委派、verified provenance和调用前检查分别约束不同事实；MCP新Issue只是开放问题。待验证：人类批准不产生provider原本没有的权限，client accept也不自然证明人类点击。候选实验：准备连接后撤权、成员消息被owner转带、审批后卸载、双租户同名员工；记录何时拒绝与谁承担责任。FCoP可研究授权决定/委派证据引用，凭证签发与执行重检属于Runtime/连接器。代价是身份源和撤权一致性；不直接提出内核改动。互动切入点：被恢复的审批怎样证明仍适用于本轮实际身份？

### A2 · 未知结果、已接受报告和新会话不能合成一个成功

依据：O1 / O6 / O14 / O15 / O19 / O20 / O23 / O24。

已有证据：StaffDeck歧义写交人核对，Orca回放已有receipt，Paperclip确认checkpoint丢失后标断续；旧dispatch/interrupt又有独立身份要求。候选实验：外部账本写入后丢响应、报告已收后丢回执、重启换session、旧轮次迟报，分别统计动作/报告/回执/验收；不把新session接着做理解为状态完整恢复。FCoP研究attempt/报告/回执/未知语义，重试/退避/租约留Runtime。需要独立真值与故障注入。互动：无receipt时应保留何种可核验未知状态？

### A3 · 任务仍活跃、进程已停止与配置已恢复要独立证明

依据：O9 / O10 / O21 / O25 / O27 / O29 / O31 / O32 / O34 / O44。

已有证据：root/child SessionEnd、后台helpers进程树、MCP共享进程和Git启用状态各有边界。WSL配置策略今天已变，不能照搬昨日结论。候选体验优先固定版StaffDeck和OpenHands，其次Orca跨Windows/WSL迁移，观察正常/崩溃/取消、退出未确认时升级是否停止。共享进程节约资源却增加隔离/所有权代价；进程组、idle、host config属于Runtime，不自动进入FCoP内核。竞品主雷达StaffDeck/Paperclip学习高、Orca第二圈加密专题，不因commit多改称企业成熟。

### A4 · 独立复核：本轮补核真实模型负结果，不包装成顺序优势

依据：O11 / O35 / O36 / O37 / O38 / O41 / O42 / O43 / O48。

已有证据：11月25日独立研究36次判定未见先报告劣势，不能据此强制把报告放最后；原文缺失组依岗位指引暂缓，不证明所有Agent能主动发现缺件。真实工具交接暴露“记录存在但正文不可读”，修正后两单只补读一份，正式复核成功；尚未覆盖原件变化。Phoenix未见数据和judge-alignment、Langfuse输入一致性进一步说明评测管线也要受检。候选实验最高优先为银行撤回/只改日期/旧判断过期，查看接班QA能否解释复用与重验，不只看最终通过拒绝。FCoP连接证据和正式复核，模型业务判断仍独立。上游benchmark不是本地实验，本轮新实验0。

### A5 · 协议互补与开源接入：事件续订不等于永久授权

依据：O16 / O17 / O18 / O20 / O27 / O33 / O39 / O40 / O44 / O45 / O48。

已有证据：MCP连接/Events订阅/OAuth续期是不同生命周期；A2A #2521及AAIF11月19日文章是历史背景，仍非已采纳标准。FCoP文件协作、A2A远程任务、MCP工具/事件分层比较，不能同称竞品。候选开源应用需固定License/安装依赖/平台、升级迁移与交付成本；源码Apache2或MIT不推及Cloud条款。今日未安装。适合互动：事件到达只触发待判断工作，何时读取当前task scope和grant？关注current-credential、资源audience与跨用户隔离，而非把所有token写进工件。

### A6 · 供应链与数据保护必须覆盖实际内容和所有副本

依据：O3 / O8 / O9 / O13 / O16 / O21 / O28 / O33 / O36 / O38 / O47。

已有证据：manifest以外内容变化、退出码、shell包装、敏感字段名、hidden artifact、TS/Rust评测对象都可能改变真实边界。待验证：签名/内容digest/日志脱敏各证明有限，不能互相替代。实验候选用合成标记覆盖encoded body、structured/meta、config key、trace、handoff和重放，并对确认后并发写、symlink/隐藏文件设负例。FCoP研究来源/派生/版本引用，执行拦截与存储清理由Runtime落实；保留hash不证明原文可取回。维护代价是血缘/扫描与兼容回归，尚未形成开发评审。
