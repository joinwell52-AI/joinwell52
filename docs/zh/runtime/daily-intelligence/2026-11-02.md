## 2. Langfuse：Gateway key 重新检查所有者权限

**#19542 MERGED; release not verified**

此前只查 key 自身角色，绕过应用的角色变更可能让已降权/离职用户的 key 继续调用。现在 resolve cache miss 时同步检查 owner 的组织权限，不具 gateway:invoke 返回 403；service-account key 不变。带外变更受缓存 TTL 约束，默认最多约 60 秒；应用内降权原本会立即删除 key 并驱逐缓存。

待验证：凭据有效不代表所有者仍有权限，撤权时延要单列。值得互动：缓存失效、恢复角色和 service-account 归属边界。

[PR #19542](https://github.com/langfuse/langfuse/pull/19542)

## 3. AG2：A2A 按产物身份统一流式与轮询账本

**#3494 MERGED; release not verified**

FCoP 待验证：重连/轮询不能靠字符串拼接猜完成，须有 artifact 与 turn 身份。值得互动：同 ID 跨轮复用、全量重发、混合 part 的一致性。

[PR #3494](https://github.com/ag2ai/ag2/pull/3494)

## 4. OpenHands：重复暂停可恢复，历史加载不依赖不可用运行时
