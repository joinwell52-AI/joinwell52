# 每日研究

每日研究是一篇按日期发布、可以独立阅读的观察报告，不是简单链接汇总。

每一期原则上包含三个固定栏目：

## 学术与论文观察

搜集当天值得关注的论文、研究方法与学术讨论，整理其问题、方法、证据、局限以及与 TMPA 的关系。

## 行业与数字员工观察

跟踪数字员工、企业 Agent、控制面、治理、岗位化产品与工作 Runtime 的最新发展，并形成架构判断。

## GitHub 与工程观察

跟踪开源 Agent、Runtime、Workflow、Skill、恢复、可观测性与多 Agent 工程项目，分析其对 CodeFlowMu 的可借鉴价值。

每个栏目都应完成：

```text
搜集 → 整理 → 探讨 → 影响判断
```
