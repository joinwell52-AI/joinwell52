# Digital Employee / 数字员工

## Governing definition / 纲领定义

A Digital Employee is a persistent, software-defined organizational work unit represented externally by a **Position** and executed internally by a **managed work team**.

数字员工是组织内部一个由软件定义、持久存在的工作单元：对外表现为**岗位**，对内由**受管理工作团队**执行。

- [Read Digital Employee Architecture V0.2 / 阅读数字员工架构 V0.2](./architecture)

## Stable relationship / 稳定关系

```text
Position → WorkOrder → Plan / Workflow → Operation Node
→ CodeFlowMu Runtime → TMPA / FCoP evidence
→ Outcome → Evaluation and improvement
```
