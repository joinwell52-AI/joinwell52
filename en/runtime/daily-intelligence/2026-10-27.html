2. Zhao-linked AEGIS tests the gateway with an agent that follows injections ​

Status：COMMITTED; UPSTREAM RESULTS, NOT LOCALLY REPRODUCED

Commit 9cc08d1 adds adaptive AgentDojo experiments and artifacts. In an earlier Haiku 4.5 experiment the agent never realized an attack, which could not establish gateway protection. A local qwen3-8b agent now realizes 61 of 249 undefended banking/Slack attack pairs; those 61 become targets for four rewrite rounds. Verdict-only and white-box feedback each flag/hold 60/61 (98.4%), with 1/61 escaping. Escape requires both AgentDojo security success and an allowed sink tool. These are upstream results, not locally reproduced or a universal safety rate.

The README identifies Aojie Yuan, Zhiyuan Su and Yue Zhao and links USC FORTIS; this attribution does not extend to unrelated projects named Aegis. Pending lead: separate model refusal from gateway enforcement. Interaction: the escaping path, benign multi-step hold costs and final approval semantics.

Cross-project synthesis and disposition ​

  • Bind authorization to real actions: rewritten Codex arguments, OACP content pins and post-interpolation CrewAI paths show why static approval does not replace call-time checks.
  • Recovery must not execute twice: Paperclip preparation ownership, Eigent request identity, Paradev outboxes, OAuth callbacks and file locks converge on this requirement.
