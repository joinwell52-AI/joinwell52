2026-11-18 Agent Research and Competitive Intelligence ​

Core judgment: governance is becoming explicit data authorization, evidence-gated recovery, repeatable evaluation and cross-client audit. Multi-agent delivery also needs distinct child outcomes, result consumption and actual independent review.

Started 2026-11-18 10:05:23 Asia/Shanghai. Fresh main Registry: 47 people; 88 original repository entries, 264 first-page queries. Continue 2026-11-17T024823Z per-source baselines while preserving older gaps. Dates below are UTC. Merged does not mean released; local experiments, articles and development assignments: zero.

Factual observations ​

O1 ADK stops implicit session-state disclosure ​

Committed November 17, breaking security change. MCP prompt arguments no longer implicitly select session-state strings by server-declared names. Only developer-supplied arguments are sent, none by default. Existing parameterized prompts require migration; this is not proof of a production leak.

Research analysis ​

A1 Recovery starts with execution evidence ​

O2 · O3 · O4 · O5 · O8 · O9 · O11

Supported: OpenHands blocks post-send retries, Paperclip requires pre-execution evidence, and Orca separates human waiting from active work. Unverified: whether local CodeFlowMu restart preserves these distinctions. Candidate: inject pre/post-send timeout, full disk and restart while awaiting approval; measure duplicates, waiting and recovery latency. Compare state/receipt/evidence at FCoP; budgets, leases and reserves belong to Runtime. Costs include fault injection and unknown outcomes. Topic: what evidence permits safe takeover?

A2 Enterprise governance extends across identity, audit and evaluation ​

O1 · O15 · O21 · O23 · O24 · O25 · O27 · O28 · O34

Supported: Agent365 visibility, Entra identity, Evals regression and explicit MCP arguments address different layers; browser integration expands signed-in access. Unverified: an end-to-end pre/post-action control loop. Copilot Evals is a trial candidate after checking license, installation source, run approval and local-data scope. Compare CodeFlowMu role identity, credentials and audit separately; do not infer central authentication requirements for FCoP. Costs include enterprise setup, privacy and model use. Topic: can evaluation assert that a sensitive effect did not occur?

A3 Delegation, root outcomes and independent review need distinct evidence ​

O7 · O10 · O12 · O13 · O16 · O20 · O29 · O33

Supported: child hooks once completed the root, resolved reviewers can be skipped, and accepted outputs need never reach inference. Unverified locally. Candidate: research→synthesis→independent-review with late child completion, identical outputs/distinct IDs, parent steering and approval resume; compare requested versus actual dispatch, consumption and acceptance. FCoP can compare task/artifact/provenance; cost attribution is not authority inheritance. Costs are durable IDs and acceptance steps. Topic: prove that independent review actually occurred.

A4 Protocol watch: event wakeup is complementary integration ​

O6 · O7 · O17 · O26 · O31 · O35

Supported: event subscriptions, Runner compatibility, rendered schemas and effective skill versions each have contracts. Event Streams is an external source, not a same-layer artifact-coordination replacement. Unverified: disconnect recovery, duplicates and semantic preservation. Candidate: replay duplicate/reordered/disconnected events offline, measuring consumption and explicit gaps without claiming upstream exactly-once. Costs include adapter persistence, compensation and migration. Trial Beads RC only on backed-up copies.
