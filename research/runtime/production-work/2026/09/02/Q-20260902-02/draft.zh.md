# 已安装，不等于已授权

一个企业智能体看到连接器标记为 **Enabled**。应用几个月前获批，选中的账户昨天被切换，目标资源今天早上撤销了访问权。把可见标记直接当作执行权限，就是把多项持续变化的事实压缩成一个已经过期的答案。

安装状态说明某项能力可以被提供，却不能证明谁正在行动、当前选中哪个关联账户、提供方允许访问什么、运行时策略是否放行本次发生，也不能证明外部系统最终修改了什么。

三个一手样本分别揭示了这种区别。OpenAI 的 Epic 集成文档把组织可用性与应用配置，同每位临床人员的登录、已批准范围和既有病历权限分开。Microsoft 记录了配置在 Entra Agent ID 上的连接器权限，也记录了连接器策略与数据丢失防护在运行时的重新验证。固定版本的 Codex 实现把选中的账户关联身份和工具信息送入应用工具策略判断。

它们不是同一种协议。比较的价值更窄：**连接器权限是分层的，Installed 或 Enabled 标记不能替代调用时授权。**

## 可用性和授权回答不同的问题

管理可用性回答组织是否提供连接器。配置能力回答智能体能够尝试调用哪些工具或范围。两者都是前提，却都没有识别某次调用中的实际行动主体。

OpenAI 的 Epic 文档把边界写得很具体。工作区与应用设置不会扩大临床人员既有的病历权限。用户仍需登录，批准范围仍有边界，目标系统继续执行自己的访问规则。因此，连接器可以被正确安装，而特定人员仍无权访问特定记录。

Microsoft 的模型揭示了另一层分离。连接器 API 权限可以配置在持久的智能体身份上，而连接器运行时、Advanced Connector Policies 与 DLP 控制仍会重新判断路径。持久配置描述能力；当前策略决定这一次是否可以执行。

## 账户关联是授权主张的一部分

连接器名称不是行动身份。同一个连接器可能对应多个关联账户、租户或认证上下文。如果所选账户会变化，只记住“用户批准过这个连接器”就过于粗糙。

引用的 Codex 版本把选中的账户关联身份、工具身份与注解送入应用工具策略判断。这是针对一个版本的实现证据，不是通用架构证明；但它说明了正确的问题：授权属于特定关联关系下的一次具体工具调用，而不属于抽象连接器标签。

记忆中的批准至少应绑定连接器、工具、账户关联、目标范围和相关发生条件。切换账户、改变工具、扩大目标或撤销权限，都应使受影响的关系失效，而不是假装安装事实本身改变了。

## 六层构成有边界的权限链

受治理的连接器调用至少需要六项可分别检查的主张。

第一，管理可用性：环境是否提供连接器。第二，配置能力：智能体配置是否允许该工具或范围。第三，行动主体或账户关联：提供方将识别哪个身份。第四，目标资源权限：该身份此刻能否作用于该对象。第五，运行时策略：当前发生是否满足组织与任务约束。第六，提供方效果证据：外部系统接受或改变了什么。

前两层描述可用能力；中间三层决定此刻是否授权这次尝试；最后一层记录结果。任何一层都不能安全推出另一层。

这种分离也明确了事实所有者。管理员管理可用性，智能体配置管理暴露能力，身份系统建立行动者，提供方拥有目标权限，运行时策略评估当前条件，提供方回执或对账状态证明外部效果。

## 授权决定不是效果回执

调用前的判断可以授权一次尝试，却不能证明提供方已经接受。客户端看似成功的响应可能丢失、重试，或者无法明确对应某项外部更改。反过来，提供方拒绝也不等于本地策略判断错误。

对于有后果的行动，应把准入决定与外部效果记录保存为两类证据。响应丢失时，应查询提供方状态，或在提供方支持时使用幂等机制。仅因本地日志缺少成功标记就重放调用，可能复制已经发生的效果。

引用来源没有证明恰好一次执行、不可变审计历史或共享回执格式。这些仍是设计要求，而不是来源支持的产品事实。

## 单一状态仍然可以存在

运维界面需要简洁。只要明确它总结的是可用性，而不是授予无限执行权，一个 Enabled 标记仍然有用。

危险发生在系统简化展示时也丢掉底层分层。可靠的运行时可以展示一个状态，同时保存每项事实、时效和责任主体。必要层缺失或过期时，应闭合失败，并解释无法建立哪项主张。

撤销语义也会更精确。目标权限撤销只使目标授权失效；账户切换只使行动者绑定失效；策略变化只使本次发生的决定失效。它们都不改变“连接器曾被安装”这一历史事实。

## 比较边界必须严格

这些样本采用不同架构、术语与执行点。官方文档描述预期行为，不是独立复现；源码样本只证明固定版本向一次策略判断传递了哪些信息。

现有证据没有证明通用连接器授权协议、凭据隔离、恰好一次效果或统一撤销语义。它支持的结论更窄：管理启用、配置能力、行动身份、目标权限、运行时策略与提供方效果必须保持为不同主张。

仍待解决的问题包括：怎样设计不泄露凭据的可移植权限回执；运行时如何表示它能查询但不能控制的提供方权限；哪些变化必须要求显式重新批准；以及连接器响应丢失时如何对账外部效果。
