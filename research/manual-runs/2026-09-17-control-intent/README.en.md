## Reproduce

Use Git, tar, Python 3, Node.js and npm. Run the commands in [README.md](./README.md#复跑). setup.mjs fetches exact revisions and preserves upstream license files; source trees are not redistributed here. Install dependencies with npm ci --ignore-scripts. The four probes print JSON; recorded outputs are in results/.

Only synthetic data and isolated temporary files are used. No personal credentials, provider calls, real model launches, production data or full scheduler runs. Source extraction checks its anchors. These are independent research probes, not official upstream tests.

Discussion drafts, posted comments and receipts are deliberately kept outside this public package.
