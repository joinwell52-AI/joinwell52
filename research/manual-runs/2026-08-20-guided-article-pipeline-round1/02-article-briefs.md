# 2026-08-20｜三篇 Article Brief

## T1｜技能不是工具权限

- **目标读者：** Agent 平台、MCP 宿主与 IDE 工具链工程师。
- **读者痛点：** 行为提示、工具目录和授权合并后，Agent 容易过载或越权。
- **核心问题：** “会怎么做”“能调用什么”“这次调用是否安全”“谁批准”为什么要分开？
- **唯一主张：** 可靠的 Agent 能力面至少需要行为手册、角色工具能力、操作影响和人工批准四层；前一层通过不能代替后一层。
- **原创价值：** 用 CodeFlowMu 固定提交的真实路由、能力门、操作策略和批准生命周期，把最小权限从口号落成可测试链；同时公开 live MCPInjector 尚未实现与全工具前置状态绑定尚未验证。
- **文章类型：** 治理机制 + 代码实现。
- **论证节点：** 现实事故 → 四层模型 → CodeFlowMu 路径 → MCP/NIST 对照 → 批准生命周期 → 35 个定向测试 → 边界。
- **证据身份：** 3 个外部官方来源、5 个第一方实现、22/22 基础门禁测试 + 13/13 批准服务测试。
- **示例/图：** 同一 `write_file` 在项目内与项目外的不同裁决；四层责任图。
- **风险：** 不把加载技能写成授权；不把 stub MCPInjector 写成 live 能力；不把 NIST 写成 Agent 专用标准。
- **读后行动：** 按四层清单审查自己的 Agent 工具接入。
- **与系列区别：** 管“能不能做”，不谈项目根或报告归属。
- **Brief Gate：** PASS。

## T2｜项目执行链安全换根

- **目标读者：** 多项目本地 Agent Runtime、IDE 和 MCP 工程师。
- **读者痛点：** UI 已切换，后台组件仍使用旧项目根，导致改错代码和写错账本。
- **核心问题：** 项目切换需要同时重绑定哪些组件，怎样证明同根？
- **唯一主张：** 项目切换是有序上下文重绑定，不是 UI 变量；旧工作先停止，新根持久化后重建全部项目作用域组件，恢复前必须核对同根不变量。
- **原创价值：** 从公开实现提炼 Runtime/MCP/Watcher/Agent/任务/证据的同根合同和部分回滚边界。
- **文章类型：** 机制 + 实操检查表。
- **论证节点：** 改错目录事故 → 七个根 → 切换时序 → 请求上下文 → 失败回滚 → 测试 → 限制。
- **证据身份：** Node.js、VS Code 两类官方资料；3 个第一方实现；27/27 测试。
- **示例/图：** 项目 A→B 时序；同根摘要对照。
- **风险：** 不使用“原子切换”；不承诺第三方扩展不缓存旧根；不把安装根保护写成 OS 沙箱。
- **读后行动：** 添加四个失败回归和七项同根检查。
- **与系列区别：** 管“在哪做”，不谈角色权限或报告验收。
- **Brief Gate：** PASS。

## T3｜并行报告归属

- **目标读者：** 多 Agent 平台负责人、PM 与验收链工程师。
- **读者痛点：** 并行报告因时间、线程或正文相似度被挂到错误任务，错误传播到汇总和下游依赖。
- **核心问题：** 报告如何确定性归属任务，歧义时系统该做什么？
- **唯一主张：** 辅助展示可以做最佳努力匹配，验收必须依赖显式身份和唯一父关系；冲突或 QA 缺失时停止汇总。
- **原创价值：** 把 W3C/OTel 的关联思想与 FCoP 信封、CodeFlowMu 三字段门和汇总门结合，同时明确 trace 不是业务验收。
- **文章类型：** 场景案例 + 验收机制。
- **论证节点：** 串账事故 → 四种弱归因 → 报告身份证 → 三字段局限与 Runtime 注入目标合同 → 展示/验收分层 → 返工、多根与报告替代 → QA 汇总门 → 测试 → 清单。
- **证据身份：** W3C、OpenTelemetry、FCoP、4 个第一方实现、44/44 测试；“三字段一致地写错”是逻辑反例和下一步测试，不属于 44 项已覆盖用例。
- **示例/图：** 三份报告一份错挂；归属决策树。
- **风险：** 三字段规则只适用于当前关键 DEV 回执；辅助正文匹配不能写成硬门；Runtime 封包并非当前全路径能力；物理时间不能单独裁决报告新旧；QA PASS 不是外部认证。
- **读后行动：** 为报告增加显式所有者、父任务、执行轮次和替代关系，并在汇总前执行身份、版本、QA 与证据检查。
- **与系列区别：** 管“证据属于谁”，不谈工具权限或项目切换。
- **Brief Gate：** PASS。
