## Mission / 使命

TMPA Research Center is an independent, engineering-driven research program on **AI work data, agent governance, digital employees, and practical multi-agent systems**.

TMPA 研究中心是一个以真实工程实践驱动的独立研究项目，聚焦 **AI 工作数据、Agent 治理、数字员工与可落地多 Agent 系统**。

```text
TMPA       → AI work data and governance architecture
FCoP       → formal coordination and responsibility protocol
CodeFlowMu → digital employee development and runtime platform

TMPA       → AI 工作数据与治理架构
FCoP       → 正式协作与责任协议
CodeFlowMu → 数字员工开发与运行平台
```
