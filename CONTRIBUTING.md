# Contributing / 参与研究

TMPA Research Center is currently maintained as an independent research project.

TMPA Research Center 当前作为独立研究项目维护。

## Public feedback / 公开反馈

- Use GitHub Issues for factual corrections, relevant literature, reproducibility questions, and implementation evidence.
- Please distinguish verified evidence from opinion or product marketing.
- Do not submit confidential business data, credentials, personal data, or proprietary source code.

- 可通过 GitHub Issues 提交事实纠错、相关论文、复现问题与工程证据。
- 请明确区分已验证证据、个人观点与厂商宣传。
- 请勿提交企业机密、账号凭证、个人敏感信息或专有源代码。

## Editorial rule / 编辑规则

Public research documents are curated outputs. Important changes may first be discussed in an Issue and then incorporated through a versioned document update.

公开研究文档属于经过编辑的正式成果。重大修改通常先通过 Issue 讨论，再以版本化文档更新方式纳入。
